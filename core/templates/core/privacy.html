Politique de confidentialité

Vos rêves peuvent révéler des éléments très personnels (émotions, santé, relations). Ils sont traités avec le plus grand soin, uniquement pour vous rendre le service.

Données traitées

  • Compte : identifiant, adresse email, mot de passe (stocké chiffré de façon irréversible).
  • Rêves : enregistrement vocal, transcription, émotion détectée, illustration générée, dates.
  • Sécurité : adresse IP et identifiant des tentatives de connexion échouées, pour bloquer les attaques.
  • Technique : journaux de fonctionnement (durées, erreurs), qui ne contiennent jamais le contenu de vos rêves.

Pourquoi

Uniquement pour fournir le service que vous demandez : transcrire, analyser et illustrer vos rêves, puis vous les présenter. Aucune publicité, aucune revente, aucun profilage commercial.

Qui y a accès

  • Vous seul voyez vos rêves, vos enregistrements et vos illustrations.
  • OpenAI (sous-traitant, États-Unis) reçoit l'enregistrement et le récit le temps de les transcrire, d'analyser l'émotion et de générer l'image. Les données envoyées via l'API ne servent pas à entraîner ses modèles ; elles peuvent être conservées jusqu'à 30 jours pour la détection d'abus.
  • Render (hébergeur, centre de données de Francfort, Union européenne) héberge l'application et la base de données.

Combien de temps

Vos rêves sont conservés tant que vous ne les supprimez pas. Supprimer un rêve ou votre compte efface immédiatement les données et les fichiers associés. Les tentatives de connexion échouées sont oubliées après une connexion réussie.

Vos droits

  • Accès et portabilité : téléchargez toutes vos données depuis Mes données.
  • Effacement : supprimez un rêve depuis sa page, ou votre compte entier depuis Mes données.
  • Réclamation : vous pouvez saisir la CNIL (cnil.fr).

Sécurité

Connexion chiffrée (HTTPS), fichiers accessibles uniquement à leur propriétaire, blocage des tentatives de connexion répétées, données hébergées dans l'Union européenne.
